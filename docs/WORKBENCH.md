# 自媒体运营管理工作台

本地管理界面将微信公众号与视频号的内容运营集中到一个入口。企业微信继续接收制作任务和真实审核，工作台负责选题、排期、过程查看、版本素材和回执。默认不连接外部服务，也不会启动另一份 Bot。

## 启动

Python 3.11+ 即可，不需要 Web 框架、前端构建或 Node 依赖：

```bash
python3 editorial/workbench/server.py
```

默认地址 `http://127.0.0.1:8788`，与 codex-weixin 的 8787 独立。Windows 把 python3 换成 python。已装 Node 时 `npm run workbench` 自动优先选择仓库 `.venv`；可用 WORKBENCH_PYTHON 指定解释器。

读取独立部署的工作室和机器人：

```bash
python3 editorial/workbench/server.py \
  --studio /srv/editorial/wechat-content-studio \
  --bot /srv/editorial/wecom-bot-local \
  --state-dir /srv/editorial/workbench-state \
  --port 8788
```

Windows 对应使用现有目录参数；路径中有空格时加引号。服务只绑定本机回环地址，服务器安装通过 SSH 转发访问：

```bash
ssh -L 8788:127.0.0.1:8788 user@server
```

在自己电脑打开 127.0.0.1:8788。此版本面向单机运营空间，没有互联网访问、用户分级或多人账号认证功能。

## 日常使用

1. **新建选题**：填写标题、形式、平台、负责人、计划日期和制作要求，保存到工作台。支持编辑、关联既有 C 编号、归档；不同页面的并发保存有版本冲突检查。
2. **发起制作**：点击“复制企微任务”，在绑定群 @ 机器人或私聊发送。保存选题本身不会启动制作。机器人生成的 C 编号可再关联到排期。
3. **查看内容**：总览按制作、审核、草稿、需要处理展示；内容列表可按标题、C 编号和阶段搜索。详情能切换历史版本、查看标题和完整简介、播放 / 下载 MP4、查看源稿。
4. **审核**：打开实际公众号草稿预览或观看 MP4。详情提供对应版本的审核与修改指令，复制后回原企业微信会话发送。过期版本不提供当前版本的确认按钮；页面不会生成审核授权。
5. **跟踪草稿**：文章预览存在和视频号草稿上传成功分别显示。视频上传成功只取实际 record_success:true 且 syncDraft:true 的回执，本地入库或受理不等于上传成功。排期日期不触发公开发布。
6. **处理异常**：审核中心列出执行结果不明、上传失败和发送结果不明的记录。工作台不提供一键重放；结合会话和平台实际结果处理，避免重复上传或发送。

## 数据边界

| 来源 | 展示内容 | 工作台写入 |
|---|---|---|
| studio/jobs/C编号/job.json 与 vN | 选题、阶段、版本、文章、视频文案、检查与草稿回执 | 无 |
| studio/outbox | 队列状态与待核对记录 | 无 |
| bot/state 与 studio/state | 心跳、制作状态、队列数量、MCP 配置标志 | 无 |
| workbench/state/plans.json | 选题、平台、负责人、计划日期、备注、关联 C 编号、归档 | 有 |

服务按白名单提取字段，不返回整个配置、接口回执、Bot ID、Secret、Cookie、原始聊天或发起人标识。账号与连接页面区分新鲜心跳、历史检查和仅已配置；不会因旧的 authenticated:true 或 MCP 配置存在而报告已在线。

素材接口只提供版本目录里的固定文件白名单，限制路径与符号链接越界；视频支持 Range 与 HEAD 请求。文章 HTML 不直接作为同源可执行页面暴露，正文按纯文本展示，官方预览通过新页面打开。

回环 HTTP 仍检查 Host、Origin 与会话 Cookie；排期写入只接受同源 JSON。页面使用本地资源与文本节点，不从 CDN 加载脚本，不执行文章、选题或回执中的 HTML。没有对外发布、审核授权、任意文件读取或任意命令执行接口。

## 本次检查

工作台后端测试覆盖状态聚合、敏感字段排除、历史版本、过期心跳、独立排期保存、并发冲突、损坏文件保留、会话与跨源检查、媒体 Range 及路径限制。Windows 不允许创建符号链接时，该项测试明确跳过。浏览器检查使用本地页面与临时测试数据，不发送企业微信消息、不创建平台草稿。

```bash
cd editorial/workbench
python3 -m unittest test_workbench
# 已安装仓库 Node / Playwright 依赖时，可选本地 UI 回归：
node test_browser.mjs
```

浏览器回归会启动一个临时端口的本地工作台，检查导航、筛选、版本切换、选题保存与归档、窄屏溢出和无外部请求。WORKBENCH_PYTHON 可指定解释器，CHROME_BINARY 可指定已安装 Chromium。

未在 Linux 实机运行验证；浏览器测试不等于企业微信到平台的完整生产验收。
